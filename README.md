# Impact International MUN

A responsive static website for Impact International MUN — Season I.

## Files
- `index.html` — website structure/content
- `styles.css` — visual design
- `script.js` — navigation, document list and animations
- `assets/impact-logo.png` — generated conference logo
- `documents/text.txt` — placeholder conference document

## Before launch
1. Open `index.html`.
2. In `index.html`, replace `https://forms.google.com/` with the real Google Form URL.
3. Replace `documents/text.txt` with official conference documents, or add more files and entries to the `documents` array in `script.js`.
4. Deploy the folder to GitHub Pages, Cloudflare Pages, Netlify, Vercel, or another static host.
